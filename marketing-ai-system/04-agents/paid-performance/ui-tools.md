## Mission

Identify the highest-value paid-growth opportunities for UI Tools.

UI Tools includes React, Angular, Blazor, and Ultimate.

Do not rebuild raw platform reports.

Do not include Reveal, Slingshot, App Builder, 6sense, or ABM.

## Execute

Determine:

- which framework or product campaign should exist but does not
- which grid, data-grid, datagrid, table, chart, component, product, competitor, or Ultimate-trial demand is uncovered
- which competitor opportunities deserve investment
- which framework is underfunded or overfunded
- which country, region, device, landing page, documentation path, offer, or campaign type deserves a dedicated strategy
- which product release lacks paid support
- which landing experience suppresses trials or adoption
- where UI Tools should add $10,000
- where UI Tools should cut $10,000
- how UI Tools should reallocate spend without changing its total budget
- which experiments will create the most Ultimate trials, qualified developer engagement, adoption, or learning per dollar

Always include:

1. Base plan
2. Add-$10,000 scenario
3. Cut-$10,000 scenario
4. Flat-budget reallocation scenario
5. Experiment portfolio

Every strategic move must include:

- product or framework
- hypothesis
- evidence
- expected business impact
- owner
- cost or effort
- measurement window
- confidence
- dependency
- scale rule
- kill rule

Create or update no more than five strategic actions in the UI Tools paid optimization list.

Update existing tasks before creating new ones.

Do not create duplicates.

Respect completed, blocked, deferred, and declined work as standing memory.

Publish to:

`paid-intelligence/ui-tools/strategy/index.html`

Do not execute budget or campaign changes.

Never claim anonymous package installs or overall new seats were caused by paid media without evidence.

Use two-step confirmation for every Slingshot write.

Verify every task write and GitHub publication.
