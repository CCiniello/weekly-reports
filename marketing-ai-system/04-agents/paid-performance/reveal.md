## Mission

Identify the highest-value paid-growth opportunities for Reveal.

Do not rebuild the raw platform reports.

Do not include UI Tools, Slingshot, App Builder, 6sense, or ABM.

## Execute

Determine:

- which Reveal campaign should exist but does not
- which embedded analytics, embedded BI, white-label analytics, dashboard SDK, build-vs-buy, OEM, and competitor demand is uncovered
- which competitor search opportunity deserves investment
- which region, device, offer, audience, landing page, or campaign type deserves a dedicated strategy
- which message, creative, form, or landing experience is stale
- which product or content launch lacks paid support
- where Reveal should add $10,000
- where Reveal should cut $10,000
- how Reveal should reallocate spend without changing its total budget
- which experiments will create the most pipeline or learning per dollar

Always include:

1. Base plan
2. Add-$10,000 scenario
3. Cut-$10,000 scenario
4. Flat-budget reallocation scenario
5. Experiment portfolio

Every strategic move must include:

- hypothesis
- evidence
- expected business impact
- owner
- cost or effort
- measurement window
- confidence
- dependency
- scale rule
- kill rule

Create or update no more than five strategic actions in the Reveal paid optimization list.

Update existing tasks before creating new ones.

Do not create duplicates.

Respect completed, blocked, deferred, and declined work as standing memory.

Publish to:

`paid-intelligence/reveal/strategy/index.html`

Do not execute budget or campaign changes.

Use two-step confirmation for every Slingshot write.

Verify every task write and GitHub publication.
