# Universal Agent Framework

1. Load governance, shared SEO framework, product configuration, source map, field map, feedback, tracker, prior report, and prior run log.
2. Validate every source and reporting window.
3. Pull only approved data; never substitute a failed source.
4. Analyze observations, interpretations, recommendations, and assumptions separately.
5. Prioritize actions against product goals.
6. Match and update existing tasks first.
7. Create only high-confidence tasks within limits.
8. Copy the canonical report and update only run-specific content.
9. Publish only approved paths/messages.
10. Save a JSON run log and self-evaluate.

Stop for human review if more than 5 new tasks or more than 15 task modifications are proposed.
