# Task Creation Standard

Create/update only when the action:
- Supports a documented goal
- Uses an approved source
- Is not duplicate, Done, In Progress, blocked, or rejected
- Has High confidence
- Has an owner, realistic date, acceptance criteria, and success KPI

Limits:
- 5 new tasks
- 3 weekly priorities
- 1 urgent new task
- 15 modifications before review

Default timing:
- Critical tracking/config: 1–2 business days
- Technical SEO: 5–10
- On-page: 7
- Internal linking: 5
- Money-page brief: 10
- Investigation: 3
- Backlink/PR: 15
- Full production: use the existing project plan only
