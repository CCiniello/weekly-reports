# Report Quality Standard

Before publication, verify:
- Report date, windows, footer, Summary tab, and copy-summary text match.
- Every repeated metric uses the same value and freshness label everywhere.
- Product filters exclude other products/frameworks.
- Source labels and caveats are consistent.
- No retired goals, placeholders, or stale dates remain.
- Task owners reflect actual assignees; FYI people are not rendered as co-owners.
- All tabs, task views, copy buttons, feedback modal, and JavaScript work.
- The canonical HTML/CSS/JS structure was preserved.
