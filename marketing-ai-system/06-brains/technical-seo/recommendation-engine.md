# Technical SEO Recommendation Engine

Create a task only when an issue is new, rising, materially unresolved, or regressed.

Group symptoms under root causes such as locale access rules, legacy URL templates, redirect/canonical conventions, staging mirrors, sitemap generation, internal-link generation, or server failures.

Every task must include Product, Category=Technical, Recommendation=FIX or INVESTIGATE, Why it Matters, Acceptance Criteria, Step by Step Fix, Insight, Success KPI, Effort, Priority, dates, estimated time, and real URLs.
