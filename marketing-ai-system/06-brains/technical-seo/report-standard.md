# Technical SEO Report Standard

Use the latest approved product HTML as canonical. Preserve CSS, JS, tabs, glossary, logos, task views, and brand.

Required sections: VP Readout, Executive Summary, Crawl Freshness, Goal Progress Scorecard, Site Health, What Changed, Root Causes, Issues That Matter, Safe to Ignore, Dev Hand-off, Forecast and Risks, Definitions/Cheat Sheet.

Goal scorecard columns:
Goal | Baseline | Current | 30-day target | 90-day target | Long-term target | Progress | Insight | Status

Repeated numbers and dates must match everywhere.
