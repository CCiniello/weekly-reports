# Technical SEO Source Standard

Primary source: Ahrefs Site Audit only.

Do not blend GA4, GSC, Salesforce, Amplitude, or rank-tracker values into technical issue counts.

Required: health score, crawl date, URLs crawled, errors/warnings/notices, issue deltas, real example URLs, and prior-crawl comparison.

If Ahrefs fails, report the failure and do not substitute another source.
