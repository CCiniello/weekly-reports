# AI Visibility Report Standard

Use the latest approved product HTML as canonical. Preserve its tabs, CSS, JS, task views, copy button, and theme.

Required Report sections:
1. VP Readout
2. Executive Summary
3. Measurement Health
4. Goal Progress Scorecard
5. KPI Snapshot
6. Topic Performance
7. Model Performance
8. Competitor / Share of Voice
9. Citation and Source Patterns
10. Prompt Audit
11. Website Readiness
12. Weekly Priorities
13. Forecast and Risks

Goal Progress Scorecard columns:
Goal | Baseline | Current | 30-day target | 90-day target | Progress | Insight | Status

The same report ID, date, response count, visibility, rank, citations, topic values, and freshness label must match everywhere.
