# Recommendation Engine

- Owned entity listed as competitor → clean entity/competitor configuration
- Missing priority topic → add grouped prompt set
- Off-ICP prompt → remove or replace
- Relevant page exists but is not cited → improve answer-first structure, entity clarity, schema, internal links, and evidence
- Only owned content cited → pursue third-party citations
- Comparison demand without page → create comparison page
- Category visibility at zero → build or upgrade category pillar
- Docs cited but product unnamed → strengthen product/entity connection
- Brand ambiguity → improve Organization/SoftwareApplication/entity consistency
- Crawlability issue → validate robots, llms.txt, canonicals, and AI-bot access

Every task needs title, why, evidence, steps, acceptance criteria, success KPI, owner, dates, priority, effort, goal, and confidence.
