# Measurement Health Standard

Check:
- Correct brand/entity
- Correct competitor set
- No owned products treated as competitors
- Priority topics covered
- Prompt relevancy and sample size
- Stable weekly methodology
- Models comparable
- Prompt changes logged

Status:
- Red: critical setup error
- Amber: usable but incomplete
- Green: decision-ready

Rebaseline after material changes to prompts, topics, competitors, entities, models, or sample size.
