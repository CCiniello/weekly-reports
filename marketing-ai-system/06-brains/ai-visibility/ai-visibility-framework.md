# AI Visibility Brain

## Mission
Improve visibility, ranking, and citation presence in AI-generated answers by connecting Amplitude AI Visibility, prompt/topic quality, source patterns, website readiness, and a limited set of high-leverage actions.

## Required sequence
1. Load governance and product configuration.
2. Read feedback, current tasks, and prior report.
3. Pull the latest completed Amplitude report.
4. Validate brand, topics, prompts, competitors, models, and sample size.
5. Label Fresh, Partial, Stale, Unavailable, or Rebaselined.
6. Audit measurement setup.
7. Analyze progress against every 30-day and 90-day goal.
8. Analyze topics, prompts, models, competitors, citations, and sources.
9. Audit website readiness.
10. Update existing tasks before creating new ones.
11. Build the canonical report.
12. Publish, post summary, and save a run log.

## Priority order
1. Measurement setup
2. Entity and competitor cleanup
3. Prompt completeness
4. Website technical readiness
5. Existing-page optimization
6. New pages/content
7. Third-party citations

## Limits
- Maximum 5 new tasks
- Maximum 3 weekly priorities
- Group prompt changes into one task
- Do not duplicate SEO-owned work

## Required report behavior
Every goal must visibly show baseline, current value, 30-day target, 90-day target, progress, status, forecast, and confidence.
