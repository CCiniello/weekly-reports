# Shared SEO Weekly Framework

Every product agent:
1. Reads feedback and tasks first.
2. Pulls approved live data.
3. Measures the product's primary goal.
4. Reviews completed work against live performance.
5. Selects the few highest-leverage moves.
6. Syncs tasks.
7. Preserves and updates the canonical report.
8. Publishes the team summary and run log.

Shared rules:
- WoW for clicks, impressions, and sessions.
- Use meaningful longer windows for rank, authority, and adoption.
- Flag rank moves only when ≥3 positions or crossing page 1, unless a #1 goal requires any slip to be flagged.
- Keep gap sweeps monthly.
- Never reconcile modeled traffic with measured sessions.
- Brand-level AI visibility must be labeled as such.
- React and Angular adoption = npm.
- Blazor adoption = NuGet only after validated.
- Reveal and Slingshot lead metrics = distinct email in Salesforce.
