Week of July 26, 2026 vs Luzmo · Explo · Qrvey · Domo
1The week in one read
First edition — baseline, no prior report to diff against. Everything here is a new standing read; from next week we lead with what changed. Two things define this week. First, the biggest M&A event our category has seen in years: Domo agreed to sell substantially all of its assets to Progress Software for ~$400M on July 22 — its ~2,400 customers, including Domo Everywhere embedded accounts, now face an ownership change closing by Nov 30. Second, an MCP / AI-agent arms race: Qrvey (9.4, GA this month) and Luzmo (June release) both shipped embedded MCP servers and agent APIs in the last six weeks. Reveal has conversational AI but no published MCP server or agent API — this is the gap forming against us. Meanwhile Explo continues winding into Omni (12-month sunset clock started Oct 2025).

2Cadence read
Qrvey and Luzmo are the fast shippers — both on roughly monthly release cycles and both have now planted a flag on the same ground: embedded MCP servers + agent APIs. The category narrative has moved in one quarter from "dashboards in your app" to "analytics your customers' AI agents can query." Domo's velocity is now a question mark given the Progress sale. Explo's is zero.

Where this closes a gap we sell against: our "True SDK, native, no iFrame" story is still differentiated on embedding depth — none of the June/July releases touch that. Where it opens a new gap: if a prospect's RFP asks "do you expose an MCP server / agent API?", Reveal currently answers with conversational AI but no published agent endpoint. We need a public answer.

2Honest read
We win decisively on embedding depth, white-label, deployment flexibility, and pricing — the pillars our ICP (regulated, on-prem-capable SaaS/ISVs) actually buys on, and the ones our own G2 reviews echo. We have two real gaps: (1) modern lakehouse connectors — no Iceberg/Delta yet, flagged by a customer in a recent review; and (2) the AI-agent surface — competitors now publish MCP servers and agent APIs while we lead with conversational AI only. Neither is fatal, but both will show up in technical RFPs this quarter. A flattering matrix would hide these; hiding them loses deals.
