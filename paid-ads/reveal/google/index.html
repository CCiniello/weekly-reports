1How to read this
Reveal plays in an expensive, high-intent space — a high CPC is not a reason to cut. If a query contains embedded analytics, embedded BI, white-label, OEM analytics, or a competitor + embed/pricing/alternative, it’s on-strategy and we keep it. We only trim genuinely broad or junk queries. The keyword book is already deep (256 terms), so growth is about the few real gaps — not loosening match type (phrase brought noise before).
