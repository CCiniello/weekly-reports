Demand-coverage gaps (grid/table/charts/component/competitor/brand)

  • React — "ag grid" (5,700/mo, KD14) + "tanstack table" (1,500/mo, KD18): uncontested competitor terms nearly matching React's entire owned category (~6,000/mo) combined, sitting in an already-funded ad group. Highest-confidence, $0-incremental move in the account.
  • Angular — Angular Material + PrimeNG (5,900–6,100/mo): 4.7–11.8× Angular's own product-term volume. Largest absolute gap in the account; sizing blocked on Google Ads reconnection to check current coverage.
  • Blazor & Ultimate — bare competitor brands (telerik/devexpress/syncfusion, 3,400/mo combined): the real competitive demand for both Blazor and Ultimate sits on un-qualified brand terms, not "blazor + X" or suite-branded queries. This is one finite pool that both frameworks are strategically eyeing — they must be coordinated, not independently funded, or they'll bid against each other and inflate CPC.
  • Ultimate — no owned demand at all: "ignite ui ultimate," "ui component suite," "enterprise ui components" all return 0 measurable US volume. There is no brand or category moat to defend.

Landing-experience & page coverage

Per the Search Intelligence report's standing review: React and Blazor have Grids pages; Angular has one too. Ultimate has no Grids page. Blazor and Angular have Compare pages; React and Ultimate do not. This matters directly for this run's finding — both attributable framework→Ultimate cross-sell touchpoints this window traced through a framework page (React video, Blazor compare page), because Ultimate has no equivalent asset of its own to capture that intent directly. Building one is a prerequisite for the Ultimate conquest campaign proposed in Budget Scenarios, not an optional nice-to-have.

Is Ultimate cpc trial volume increasing? (with a disclosed discrepancy)

The two specialist reports disagree on the exact current-week number, though both agree on direction. Both start from the same Salesforce query and the same root fact: on Jul 30, one person (xin.zhang@3dmotion.de) submitted the Ultimate trial form three times in five minutes under an untagged campaign. Search Intelligence's convention: dedupe the three submissions to one legitimate trial from one real person → current week = 4, prior week = 1, +300% WoW. Landing/Adoption's convention: exclude the entire burst cluster until the bot/duplicate audit clears it → current week = 3, prior week = 1, reported as the safer number to trust today. Neither number is wrong given its stated methodology — but they are different numbers for the same week, and no one has reconciled which convention this program should standardize on. The open "Ultimate Paid: Audit the Jul 30 trial burst" task (due Aug 12) is the right place to settle this; until then, report the range as 3–4, not a single number. The independently re-verified trailing-30-day total (17, both reports agree after Search Intelligence's same-day correction) is solid and not in dispute.

Package adoption & new-seat trend (directional, not attributed to paid)

Both specialist reports agree the week-over-week swings (React combined npm −60.9% WoW / Angular −33.4% WoW this window) are single-day CI/CDN spike reversion in the -core/-charts packages, not real developer-demand change — a spike-adjusted metric is already an open task (due Aug 11). The steadier read is 30-day: React combined npm 70,505, down 26.9% MoM, with the flagship igniteui-react package itself down 35.4% MoM — a genuine decline worth watching. Angular combined npm 108,512, up 44.2% MoM, but the flagship igniteui-angular package itself is only +11.3% MoM ("least volatile Angular package" per Search Intelligence) — the headline MoM figure is inflated by noisy companion packages. Blazor has no reliable npm/NuGet trend (2-point snapshot only). No package-install or overall new-seat number is claimed as paid-caused anywhere in this report — no valid click-to-install attribution mechanism exists for any package, per configuration.md and the marketing constitution.
