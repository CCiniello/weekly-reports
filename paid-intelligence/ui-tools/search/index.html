What's actually true this week

  1. The paid program is flying blind on its two primary channels, again. Google Ads (account 9179838229) and GA4 (property 516222862) both failed via Supermetrics with the same root cause: the team's Supermetrics trial expired 2026-08-05. This is the second consecutive week of total blindness on spend, impression share, search terms, device/geo, and on-site session data. Microsoft Advertising is a separate, unrelated failure — it has simply never been authenticated in Supermetrics, so the "Google + Microsoft" comparison this program is built around has been Google-only (and this week, entirely empty) since inception. Both are logged as open tasks; see Tasks tab.
  2. Ahrefs confirms a real, fully-costed conquest opportunity sitting untouched: "ag grid." At 5,700 searches/month (US) and a low keyword difficulty of 14, this single competitor term is worth almost as much search volume as React's entire owned category vocabulary (grid + data grid + table + charts + components + library terms, ~6,000/mo combined). This doesn't require new budget — it can be folded into the already-funded Search-Compete-React campaign (+$50/day approved 7/24) once Google Ads access returns.
  3. Ultimate trial volume is directionally up, but on a small and previously-inflated base. Live Salesforce data (not carried) shows the "Jul 30 burst" that looked like +500% WoW was actually one person (xin.zhang@3dmotion.de) resubmitting the trial form three times in five minutes. Deduped, the real signal is 1→4 distinct cpc-attributed trials WoW (+300%) — still positive, still too small a base to call a trend, and this run resolved the standing audit task with a specific root-cause theory (a UTM/gclid drop on repeat form submission).
  4. React and Angular have no click-to-lead visibility in Salesforce at all. Zero React or Angular cpc-attributed conversion events exist in the last 5+ weeks of Lead_Event__c data, because CTA key-event tracking isn't implemented on either framework's pages yet (open tasks already cover this). This isn't a reporting gap this run created — it's a standing measurement gap that makes "0 conversions" look like a performance problem when it's actually an instrumentation problem.
  5. Adoption signal is mixed and partly artifact-driven. React's flagship package (igniteui-react) is down both WoW (−14.4%) and MoM (−35.4%). Angular's flagship (igniteui-angular) is up MoM (+11.3%) but down WoW (−12.1%). The companion "-core" and "-charts" packages on both frameworks show single-day spikes 5–50x baseline that read as CI/CDN cache-refresh bursts, not organic developer adoption — already flagged in a standing task. None of this is attributed to paid media.

Where the next UI Tools search dollar should go

With no live spend data, this is a readiness recommendation, not a budget reallocation — execute the moment Google Ads access is restored:

  • React — highest confidence, no incremental budget: add "ag grid" (exact + phrase) to the already-funded Search-Compete-React ad group. 5,700/mo volume, $1.10 CPC, difficulty 14 — the single best-costed opportunity found this run.
  • Angular — already an open, high-confidence task: Angular Material + PrimeNG competitor volume (5,900–6,100/mo depending on basket) is 4.7–11.8x Angular's own product-term volume. Confirmed independently this run via a second Ahrefs pull; scoping is blocked on Google Ads reconnection to check current impression share on those terms before sizing a conquest ad group.
  • Blazor — a new observation, not yet a task: Blazor-qualified competitor terms are thin (100/mo), but real competitor demand for Blazor buyers concentrates on bare brand terms — telerik (1,700/mo), devexpress (900/mo), syncfusion (800/mo) — not "blazor"-qualified queries. A Blazor-only campaign structure that only bids on "blazor + competitor" terms misses where the demand actually lives. Worth scoping once Google Ads is back and current Blazor coverage can be checked.
  • Ultimate — no organic search demand to buy against directly. "ignite ui ultimate," "ui component suite," and "enterprise ui components" all returned zero measurable US search volume in Ahrefs. Ultimate's addressable paid demand has to ride on the same bare competitor brand terms as Blazor (telerik/devexpress/syncfusion, 3,400/mo combined) — there's no category-term or brand-term moat to defend yet.
