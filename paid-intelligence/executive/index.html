01Executive summary

This is a baseline run with a real data blackout: Google Ads and GA4 returned zero connected accounts today, so pacing, spend, impression share, and session data cannot be reported live. What is live and verified: Ahrefs demand data across every priority term, and Salesforce trial-event data for Ultimate.

The one clean signal this week: Ultimate cpc-attributed trial starts are up 25% MoM (15 in the last 30 days vs. 12 in the prior 30) — verified directly against Lead_Event__c, cross-checked source-by-source (Google cpc = 14, YouTube cpc = 1, sums to 15). But paid is a minority channel: cpc trials are only 13% of Ultimate's 115 trial starts in the last 30 days — organic (55) and direct (12) still dominate.

Framework attention is badly lopsided in the tracker, independent of any spend data. The shared UI Tools "Optimizations" list carries 31 React tasks (8 completed, 3 in‑progress, 20 open) against exactly 1 Angular task, 1 Blazor task, and zero Ultimate tasks. That's not a spend number, but it's a real, verifiable proxy for where operational attention is going, and it says React is getting essentially all of it.

Demand capture reads differently by framework. Ahrefs US volume shows React's own product terms (grid/table/charts/components ≈ 6,000 searches/mo) outweigh its competitor terms (TanStack, MUI, AG Grid ≈ 2,030/mo) — React can win on generic terms. Angular is the opposite: Angular Material + PrimeNG alone pull 5,940/mo, roughly 5.4× Angular's own product-term volume (~1,100/mo) — Angular's paid opportunity is mostly a competitor-conquest problem, not a generic-term problem. Blazor's market runs on vendor brand searches (Telerik 1,700, Syncfusion 800, DevExpress 900 = 3,400/mo) that dwarf both Blazor's generic terms (~790/mo) and Blazor-specific competitor terms (~110/mo) — a structurally different, brand-vs-brand buying problem.

Two measurement items need a leadership decision, not more analysis: (1) React has no gated conversion by design (the trial download doesn't require a form) — "0 conversions" was never a tracking bug, and the report has already been corrected to score React on cpc sessions + engagement rate, pending JJ's sign-off on permanent KPI targets. (2) The npm-installs pipe that was marked "Completed" on Aug 3 is still blocked in this reporting run — api.npmjs.org returns HTTP 403 here — so package adoption cannot be shown this run either.
