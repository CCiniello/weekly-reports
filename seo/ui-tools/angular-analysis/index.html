Plain-English glossary

Modeled organic traffic (Ahrefs)
Ahrefs' estimate of monthly visits from Google, derived from keyword rankings and search volumes. A model, not a counter.
Organic sessions (GA4)
Actual visits recorded by the GA4 tag when someone lands on an Angular page from organic search. Requires the tag to fire and the source to be connected — currently Unavailable.
Top-3 keywords
Count of queries where an Angular page ranks in positions 1–3. The placements that capture the majority of clicks.
Striking distance
Keywords ranking positions 4–15 — close enough that focused on-page work can push them into the top 3.
Engagement rate (GA4)
Share of sessions that were "engaged" (10s+, a conversion, or 2+ pageviews). GA4's replacement for bounce rate.
Domain Rating (DR)
Ahrefs' 0–100 strength score for the whole infragistics.com backlink profile. Currently 72. Not isolable to Angular.
npm downloads
Package install/download counts from the public npm registry — the closest proxy we have for real developer adoption of the Angular components.

The one-metric-one-tool rule

Every number in this brief comes from exactly one tool. Ahrefs and GA4 will disagree on "traffic" because they measure different things — a search model versus tracked on-site sessions. We report both honestly and never blend or reconcile them into a single figure.
