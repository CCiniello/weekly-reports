Executive summary

Data integrity note: Treat this week's 0% as a degraded-run artifact. The Jul 30 Amplitude report (188594) collected 8 responses / 2 model families vs the usual ~40–49 / full model set. Week-over-week deltas below are shown against that thin run and flagged accordingly; the trend chart is the more honest read.

Infragistics is tracked at the parent-brand level in Amplitude AI Visibility across a single topic — "React – Best-of & Discovery" — built from four high-intent developer prompts (best React data grid, enterprise React UI libraries, React charting, most-performant React table). Across those prompts, LLMs consistently recommend AG Grid, TanStack Table, MUI, Ant Design and Recharts. Ignite UI is not surfaced as a recommended option in any of them. The one place we show up at all is as a cited source: our blog "Best React Data Grid for Large Datasets" is retrieved and, because it names Ignite UI for React, we ride along — but the model still ranks the open-source names above us.

The strategic gap is twofold: coverage (no Angular, Blazor, or head-to-head "vs Kendo / vs DevExpress" prompts are tracked, and the "Head-to-Head Evaluation" topic sits empty with zero prompts) and content (we own almost no answer-first, list-style pages that LLMs pull from). Both are fixable and both are in this week's task list.
