Plain-English glossary
Impressions
How many times our result showed in search for a Blazor query.
Clicks / CTR
Clicks are actual visits from search; CTR is clicks ÷ impressions. Falling CTR at flat impressions = we're shown but not chosen (usually a rank slip).
Position (Δ4wk)
SERP rank vs four weeks ago. A positive Δ number means the rank got worse (moved down the page).
Money / target page
The product page we want the traffic on — here the Blazor hub and the data-grid component page.
Engagement rate
Share of sessions that were "engaged" (GA4's replacement for bounce). 0% on the data-grid page is a red flag.
Share of voice (AI)
How often a brand is named in LLM answers to a fixed prompt set, vs competitors.
The one rule
One metric, one tool. Never blend two sources for the same number. If two tools disagree, they're measuring different things (search vs on-site, real vs modeled) — we don't reconcile them, and we never fabricate. Everything above is an actual tool value.
