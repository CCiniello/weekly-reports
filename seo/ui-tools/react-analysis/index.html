Plain-English glossary

    

      
Impressions — times a page showed in results. Clicks — times someone clicked through. CTR — clicks ÷ impressions. Position — average ranking slot (lower = better; #1 is top). Page 1 — positions 1–10. KD — keyword difficulty, 0–100. Volume — est. monthly searches. DR — Domain Rating, backlink strength 0–100. Engagement rate — % of sessions that were engaged (GA4's replacement for bounce rate). north star — the one metric adoption ladders up to: npm installs.

    


    
The one rule

    
One metric, one tool. Never blend two sources for the same number. If two tools disagree, they're measuring different things (search vs on-site, real vs modeled) — we don't reconcile them. We never fabricate; we present only actual tool values, and everything here is filtered to React.
