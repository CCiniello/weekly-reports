Source-of-truth cheat sheet

URL naming law

  • Lowercase, hyphenated, one canonical form.
  • Pick one slash convention and enforce site-wide with 301s — the Sitemap tab shows how many trailing-slash duplicates exist today.
  • Max two levels deep for money pages. No query-string categories.
  • Every removed URL gets a 301 — never a delete. The 1,225 referring domains are the asset.

Executive summary

Slingshot SEO — Week 1 (reset kickoff)

Where we are. We've started the SEO reset on the existing domain — the right call, because the domain carries real authority (DR 55, 1,225 referring domains, ~150k Google impressions/week) that would take 18–24 months to rebuild elsewhere. The problem was never the domain; it's what sits on it. Today that authority points at off-ICP content and ranks too deep (avg position ~33) to earn clicks, and none of the six marketing money-pages rank yet. That's the expected starting line, not a red flag.

What we're doing this week

Leading with comparisons — the lowest-effort, highest-intent pillar. The /compare/ hub already exists, so we're optimizing it (not rebuilding), migrating the flat /slingshot-vs-asana/ page into it, and building the vs-Monday page. We already rank #14 for "agencyanalytics alternative," which proves the model works when a page targets a real buyer query.

What changed this week

  • GSC is now wired directly (Search Console API) instead of through Ahrefs — so clicks, impressions, position and CTR are first-party and trustworthy. Clicks 213/wk (down from 262), impressions up 7% — demand is there, we just rank too low to capture it.
  • The full URL inventory is mapped (new Sitemap tab): ~500 indexed URLs with heavy trailing-slash and locale duplication. This is the master list for the taxonomy cleanup and the 301 map.

Honest flags

  • AI share-of-voice has no baseline yet — Slingshot is set up for monitoring but no report has run; we need the prompt set + cadence confirmed so a first reading lands next cycle.
  • Organic demos are 0 against ~185 organic sessions/week. Expected pre-rebuild; it's the number the whole program is built to move.

The ask / what to expect. Nothing needed from you this week. Expect a temporary dip when the URL migration lands in a few weeks (4–8 weeks is normal on an IA rebuild, then recovery above baseline) — flagging now so it isn't misread as the program failing.
