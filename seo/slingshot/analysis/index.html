Source-of-truth cheat sheet · same every week — the team's standing reference

URL naming law

  • Lowercase, hyphenated, no stop-words where avoidable — one canonical form.
  • Pick one slash convention and enforce it site-wide with 301s. This alone kills a whole class of duplicate-URL cannibalization.
  • Max two levels deep for money pages. No three-level product URLs.
  • No query-string categories for indexable content — use crawlable folders (kill ?department=).
  • Every removed URL gets a 301 to its closest relevant page — never a delete. The 1,225 referring domains are the asset.

Executive summary

Slingshot SEO — Week 1 (reset kickoff)

Where we are. We've started the SEO reset on the existing domain — the right call, because the domain carries real authority (DR 55, 1,225 referring domains) that would take 18–24 months to rebuild elsewhere. The problem was never the domain; it's what sits on it. Today that authority points at off-ICP content (our biggest traffic page is a "micromanagement" definition), and none of the six marketing money-pages rank yet. That's the expected starting line, not a red flag.

What we're doing this week

Leading with comparisons — the lowest-effort, highest-intent pillar and the fastest path to qualified traffic. We've locked the baseline scoreboard, and put two content tasks live in Slingshot: drafting the /compare/ hub and speccing the first two competitor pages (vs Asana, vs Monday). We already rank #14 for "agencyanalytics alternative," which proves the model works when a page targets a real buyer query.

Why it matters

Comparison and "alternative" searches are made by marketers with a wallet open. Winning them converts far better than the vanity traffic we have now. In parallel we're seeding the branded "Slingshot vs …" pages that LLMs increasingly cite — the category is being defined inside ChatGPT and Perplexity right now, and we want Slingshot to be the default answer.

Honest flags

  • Google Search Console isn't feeding Ahrefs yet — so clicks/impressions/queries are dark this week. Getting that connection verified is the top data fix.
  • AI share-of-voice has no baseline yet — Slingshot is set up for monitoring but no report has run; we need the prompt set + cadence confirmed so a first reading lands next cycle.
  • Organic demos are 0 against ~185 organic sessions/week. Expected pre-rebuild; it's the number the whole program is built to move.

The ask / what to expect. Nothing needed from you this week. Expect a temporary dip when the URL migration lands in a few weeks (4–8 weeks is normal on an IA rebuild, then recovery above baseline) — flagging now so it isn't misread as the program failing.
